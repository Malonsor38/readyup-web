How this was built

I'm not a web developer. I built Ready Up with Claude as a design and engineering collaborator, which is also how the backend, hosting and email got set up. We ask members to be transparent about AI in their own work, so it would be poor form to be vague about mine.

It also means this is a functional first pass, not a designed one. I'd genuinely like to work with web designers and graphic artists to give it a proper identity and real artwork. If that's you, get in touch on LinkedIn.
